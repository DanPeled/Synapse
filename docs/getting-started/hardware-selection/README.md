# Hardware Selection

Synapse runs on a Linux **coprocessor** connected to your robot. You can use a single-board computer such as an Orange Pi 5 or Raspberry Pi 5, or almost any 64-bit Linux device with a supported camera and enough CPU for your pipeline.

This section covers:

- [Selecting Hardware](selecting-hardware.md) — what to look for in a coprocessor, camera, storage, and power supply.
- [Deploying on Custom Hardware](deploying-on-custom-hardware.md) — the requirements a device must meet for the installer.
- [Performance Matrix](performance-matrix.md) — measured performance on common devices.

{% hint style="tip" %}
If you are buying new hardware, an Orange Pi 5 with 8 GB of RAM and a global-shutter USB camera is a good default for AprilTag pose estimation.
{% endhint %}
